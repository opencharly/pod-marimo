## Summary

This candy pinned `layer-cuda:v2026.290.1513`, whose transitive `layer-nvidia` pin is the `#12` commit `054aa7702ebe…`. `#12` removed the `stdout:` matcher so the Arch arm could skip honestly, and left the guard that decides whether to skip:

```
if [ ! -e /etc/dnf ] && [ ! -e /etc/yum.repos.d ]; then exit 0; fi
```

That skips only when **both** are absent, while the comment above it states the intent as *"no DNF at all"*. Arch-family arms have no `/etc/dnf`, but `/etc/yum.repos.d` **does** exist there, so the arm fell through to the Fedora assertion and failed. `layer-nvidia#14` fixed that guard; `layer-cuda#17` advanced its own nvidia pin to the fix and minted **`v2026.290.2052`**.
